Thank you for helping the **Edinburgh Decentralisation Index Dashboard**! This guide walks you through sharing a dataset with us using IPFS (InterPlanetary File System).

Many blockchain datasets are extremely large (multiple GBs or even TBs). Instead of uploading files through email or cloud storage, we recommend IPFS  because it provides:

- efficient sharing of large datasets
- content-addressed storage (every dataset has a unique CID)
- resumable downloads
- decentralized distribution
- easy verification that data has not changed

You only need to send us the **CID (Content Identifier)** after uploading your
dataset. If you think that a different mechanism is more appropriate for your
infrastructure, please <AppLink href="mailto:edi@ed.ac.uk">contact us</AppLink>
instead.
