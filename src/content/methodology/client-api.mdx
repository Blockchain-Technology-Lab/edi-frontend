On the Client-API layer, decentralisation is evaluated based on the distribution of RPC traffic across client API providers (for example node-as-a-service and public RPC endpoint operators).

Traffic shares are estimated for each Tranco list date. For every date, the estimated shares of all providers sum to 100%. The dashboard shows the ten providers with the highest average share individually and groups all remaining providers as "Others".
